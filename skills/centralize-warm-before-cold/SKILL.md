# Warm before cold

Use when a target account has a warm path, before starting a cold sequence.

## Run the play

Resolve the account and target contact. Review warm connections, the relationship owner, and the evidence behind each path. Check that the relevant teammates have synced LinkedIn and that the relationship is current. Choose the strongest credible path and draft a specific introduction request. Return the target, connector, evidence, and draft; flag missing sync coverage. Create a Reach-Out request only when the user authorizes notifying that teammate.

## Example prompt

Find the best warm path into [Account] before I sequence it. Show the target, connector, relationship evidence, and a draft intro request.

Use current Centralize tool schemas and returned IDs. Cite sources and mark uncertainty. Draft outreach and tasks unless requested.
