# Map-based pipeline review

Run weekly with the frontline manager. This is a management ritual on existing data.

## Run the play

Review open opportunities on the account map. Inspect recent touchpoints, buying roles, and sentiment to find single-threaded deals and unengaged decision makers. Check whether each economic buyer is actually engaged and whether the champion’s support has evidence. Propose a thread-fill action with a named target, owner, and due date for each gap; mark unassigned fields explicitly. Return a review agenda and action list. Save or assign tasks only if requested. The review does not run or flag gaps automatically.

## Example prompt

Prepare this week’s map-based pipeline review. Flag single-threaded deals and propose a named target, owner, and due date for each thread-fill action.

Use current Centralize tool schemas and returned IDs. Cite sources and mark uncertainty. Draft outreach and tasks unless requested.
