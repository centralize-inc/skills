# Single champion

Use when a customer has only one engaged contact. Add their manager and a peer before T-120 relative to renewal. Manual review.

## Run the play

Confirm the renewal date and define the engagement window. Review the map and touchpoints to verify that only one contact is engaged. Identify the champion’s manager and a relevant peer, marking inferred lines. Propose a champion-sponsored introduction and a named owner for each relationship. Return the renewal date, T-120 target date, evidence, contacts, and next steps. If renewal timing is missing, say so. There is no single-champion alert.

## Example prompt

Review [Customer] for single-champion risk before renewal. Show T-120, engagement evidence, the champion’s manager and peer, and proposed intros.

Use current Centralize tool schemas and returned IDs. Cite sources and mark uncertainty. Draft outreach and tasks unless requested.
