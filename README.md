# Centralize Skills

Reusable instructions for account mapping, warm introductions, pipeline reviews, customer expansion, and other GTM work in Centralize.

Browse the [Skills & Workflows library](https://www.usecentralize.com/skills) or download the skill folders from this repository.

## Download

- Download everything: [Download ZIP](https://github.com/centralize-inc/skills/archive/refs/heads/main.zip).
- Clone the repository: `git clone https://github.com/centralize-inc/skills.git`.
- For one skill, open its folder below and download `SKILL.md` using GitHub's Raw / Download raw file control.

## Use a skill

Each folder under `skills/` contains a complete `SKILL.md` file with its name, description, and instructions. Install the folder through your assistant's skill support, or paste the file's contents into a connected assistant when you want to run the workflow.

Connect your assistant to Centralize MCP at `https://app.usecentralize.com/api/mcp`. Available tools and data depend on the connected user's workspace, permissions, and plan. Use the current tool list and schemas. Some contact operations can start background enrichment and require write access.

These are reusable instructions run when requested. Individual skills explain manual steps, plan requirements, missing evidence, and any action that needs user authorization.

## Source and updates

This collection contains the org-chart skill and all 14 workflow instructions published in the [Centralize Skills & Workflows library](https://www.usecentralize.com/skills). The workflow files include the full instructions and example prompts, not only the card summaries.

When updating a workflow, keep its repository file and published website copy aligned. To request a skill or suggest an improvement, [open an issue](https://github.com/centralize-inc/skills/issues) with the task, example input, and desired output.
