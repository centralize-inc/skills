# Territory balance

Use to compare books by warm-path density rather than account count alone. Manual MCP analysis; no in-app report.

## Run the play

Resolve the territory assignments and accessible account sets. Define warm-path density consistently, such as available paths per account, and distinguish distinct connectors from path counts. Compare books using the same measure. Flag stale relationships, unsynced connectors, and incomplete data before drawing conclusions. Return the imbalances and proposed account moves with their rationale. Do not change ownership or territory assignments without a specific request.

## Example prompt

Compare our books by warm-path density. Define the measure, flag sync and freshness gaps, and propose territory changes with evidence.

Use current Centralize tool schemas and returned IDs. Cite sources and mark uncertainty. Draft outreach and tasks unless requested.
