# Buyer mirror

Use to compare buyer roles from the last five closed-won deals with open accounts. Manual MCP analysis; no in-app report.

## Run the play

Resolve five recent closed-won opportunities and inspect their actual buying roles, titles, and available engagement evidence. Identify the recurring buyer profile and state the sample size and missing data. Compare that profile with contacts at each open account. Return mapped matches, missing roles, and questions for the AE. A matching title is a candidate buyer, not proof that the person owns budget.

## Example prompt

Analyze the buyer roles in my last five wins. Compare them with my open accounts and flag missing buyer profiles with evidence.

Use current Centralize tool schemas and returned IDs. Cite sources and mark uncertainty. Draft outreach and tasks unless requested.
