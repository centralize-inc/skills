# Forecast gate

Use before putting an opportunity in Commit. This is a manager-enforced gate.

## Run the play

Confirm a recorded economic buyer and inspect their recent engagement. Confirm a named champion whose sentiment is Supporter, with supporting evidence. Treat missing roles, stale touchpoints, and unknown sentiment as evidence gaps. Return pass, fail, or insufficient evidence for each criterion, plus the next action to close the gap. Roles can sync from Salesforce opportunity contact roles; sentiment and map accuracy still need maintenance. Do not change the forecast or mark a title as economic buyer automatically.

## Example prompt

Check [Opportunity] against our Commit gate: engaged economic buyer and Supporter champion. Show evidence, missing data, and next actions.

Use current Centralize tool schemas and returned IDs. Cite sources and mark uncertainty. Draft outreach and tasks unless requested.
