# Coverage scorecard

Use in rep 1:1s to inspect engagement across top accounts. Plan dependent.

## Run the play

Confirm access to the enterprise-plan touchpoint coverage report and record its refresh time; it refreshes twice a day. If unavailable, use a manual MCP review of accounts, contacts, and touchpoints within the connected user’s access. Agree the account set and time window. Compare each rep’s engaged contacts, buyer coverage, and gaps, keeping the same definitions across reps. Return the coaching priorities and proposed actions. Do not present manual analysis as a live in-app report.

## Example prompt

Build a touchpoint coverage scorecard for my reps’ top accounts. State the time window, report access, refresh time, buyer gaps, and coaching priorities.

Use current Centralize tool schemas and returned IDs. Cite sources and mark uncertainty. Draft outreach and tasks unless requested.
