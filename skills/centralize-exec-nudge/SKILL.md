# Exec nudge

Use for a Stage 3+ opportunity with an executive or investor path to its economic buyer.

## Run the play

Confirm the opportunity stage and recorded economic buyer; do not infer the buying role from title alone. Find an executive or investor connection to that named person using Warm Connections. Confirm that the connector has synced LinkedIn. Draft a short nudge tied to the evaluation and a specific next step. Return the evidence, proposed sender, recipient, and draft. A Reach-Out request notifies the teammate; create one only when the user authorizes that action.

## Example prompt

For [Opportunity], find an exec or investor path to the economic buyer and draft a nudge. Flag missing role or LinkedIn evidence.

Use current Centralize tool schemas and returned IDs. Cite sources and mark uncertainty. Draft outreach and tasks unless requested.
