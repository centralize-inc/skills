# Spend by density

Use when choosing metros for field events using contacts at open opportunities.

## Run the play

Resolve the open-opportunity account set and group relevant contacts by metro using location radius filters on contacts and warm connections. State the radius, scope, location gaps, and deduplication basis. Compare contact density and available relationship owners by city. Return a ranked metro list with contact counts and named warm paths that could support invitations. This is a planning workflow, not an automatic event campaign. Verify opportunity-level buying-role filter behavior before relying on it; do not treat omitted roles as no buyer coverage.

## Example prompt

Rank metros for a field event using contacts at our open opportunities. State the radius and data gaps, and show warm connections in each city.

Use current Centralize tool schemas and returned IDs. Cite sources and mark uncertainty. Draft outreach and tasks unless requested.
