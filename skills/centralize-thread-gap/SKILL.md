# Thread gap

Use for Stage 2+ opportunities with no engaged economic buyer or fewer than three engaged contacts. Manual review.

## Run the play

Resolve the opportunity stage, map, buying roles, and touchpoints. State the engagement window and count distinct engaged contacts, not activity events. Identify whether the economic buyer is known and engaged. For each gap, find a warm path to a missing buyer or evaluator and propose the next action. Return the account, thread count, buyer evidence, target, connector, and proposed owner. Nothing automatically flags this gap; run the review through a manager or MCP.

## Example prompt

Review Stage 2+ opportunities for an unengaged economic buyer or fewer than three engaged contacts. State the engagement window and suggest warm paths to fill gaps.

Use current Centralize tool schemas and returned IDs. Cite sources and mark uncertainty. Draft outreach and tasks unless requested.
