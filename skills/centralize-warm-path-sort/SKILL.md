# Warm-path sort

Use when deciding which accounts in a rep’s book to work first.

## Run the play

Resolve the book and account owner. Count available warm paths by account, distinguish paths from unique connectors, and record the count basis. Rank accounts by warm-path count and return the top 20 with a named target and strongest path. Flag stale connections, missing LinkedIn syncs, and accounts whose path data is unavailable; unavailable does not mean zero. This is a Connections-page or MCP review, with no automatic territory rebalance.

## Example prompt

Rank my book by available warm paths. Show the top 20, strongest connector and target per account, and data gaps.

Use current Centralize tool schemas and returned IDs. Cite sources and mark uncertainty. Draft outreach and tasks unless requested.
